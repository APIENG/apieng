API Keys

Your API Key

Use this token in the Authorization header to call the APIENG REST API.

Keys expire after 1 hour. Generate a new one when it stops working.

Using your key

Measure an endpoint:

curl -X POST http://localhost:8080/api/measure \ -H "Authorization: <YOUR_API_KEY>" \ -H "Content-Type: application/json" \ -d '{"apiEndpoint": "https://api.example.com/health"}'

Fetch your stored metrics:

curl http://localhost:8080/api/metrics \ -H "Authorization: <YOUR_API_KEY>"
