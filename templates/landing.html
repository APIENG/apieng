How It Works

Simple Integration, Powerful Results

1

Install Our SDK

Add our lightweight SDK to your project with a single command. Supports all major programming languages and frameworks.

2

Configure Endpoints

Specify which API endpoints you want to monitor. Our SDK automatically starts collecting metrics.

3

Monitor & Optimize

Access real-time metrics through our dashboard and receive AI-powered optimization recommendations.

apieng.config.js 
import { ApiEng } from '@apieng/sdk';

// Initialize APIENG
const apieng = new ApiEng({
  projectId: 'your-project-id',
  endpoints: [
    {
      path: '/api/users',
      method: 'GET',
      threshold: {
        energy: 0.5, // watts
        response: 200  // ms
      }
    }
  ]
});
