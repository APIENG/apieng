APIENG Documentation

APIENG is an AI-powered green API observability platform. It measures the performance of an API endpoint, estimates the computational energy each call consumes, and uses generative AI to explain the results in plain language. This guide covers the web app and the REST API.

Getting Started

  1. Create an account and sign in.
  2. On the Metrics page, paste an API endpoint and click Measure.
  3. View per-endpoint detail, energy ratings, and AI insights.
  4. Generate an API key to automate measurements from your own scripts or CI pipeline.

Authentication

The REST API authenticates with an API key (a signed JWT) sent in the Authorization header. Generate one from the API Keys page. Keys are valid for 1 hour.

Authorization: <YOUR_API_KEY>

Measure an Endpoint

POST /api/measure

Measures the given endpoint, stores the result, and returns the metrics (including the AI explanation).

curl -X POST http://localhost:8080/api/measure \ -H "Authorization: <YOUR_API_KEY>" \ -H "Content-Type: application/json" \ -d '{"apiEndpoint": "https://api.example.com/health"}'

Response

{ "api_endpoint": "https://api.example.com/health", "method": "GET", "status": 200, "request_size": 36, "response_size": 1284, "response_time": 142000000, "energy_consumption": 3.55, "explanation": "The endpoint transferred roughly 1.3 KB ..." }

Fetch Metrics

GET /api/metrics

Returns all stored metrics for the authenticated account as a JSON array.

curl http://localhost:8080/api/metrics \ -H "Authorization: <YOUR_API_KEY>"

Energy Methodology

APIENG estimates energy as Energy (J) = Power (W) × CPU utilization × Response time (s), using a representative per-core power figure. The estimate is a relative indicator for comparing endpoints, not a certified measurement of data-centre draw. The roadmap includes a research-informed, bytes-transferred model and cloud-provider-specific coefficients.

Self-Hosting

APIENG is open-source and self-hostable. It needs an RSA key pair (for signing API keys) and, optionally, a Gemini API key for AI explanations.

# 1. Generate the RSA key pair mkdir keys openssl genrsa -out keys/app.rsa 2048 openssl rsa -in keys/app.rsa -pubout -out keys/app.rsa.pub # 2. (Optional) enable AI insights echo "GEMINI_API_KEY=your_key_here" > .env # 3. Run go run ./cmd/server.go # http://localhost:8080
